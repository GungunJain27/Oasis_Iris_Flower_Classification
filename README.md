# Iris Flower Classification 🌸

## Project Overview

This project focuses on classifying Iris flowers into three different species using Machine Learning.

The three species are:
- Setosa
- Versicolor
- Virginica

The Iris dataset was analyzed, visualized, and used to train classification models.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses the built-in Iris dataset from Scikit-learn.

The dataset contains 150 samples with four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Machine Learning Models

Two classification algorithms were used:

1. Logistic Regression
2. K-Nearest Neighbours (KNN)

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 96.67% |
| K-Nearest Neighbours (KNN) | 100% |

## Project Workflow

1. Load the Iris dataset
2. Create and prepare the dataset
3. Perform data exploration
4. Visualize the data
5. Split the dataset into training and testing sets
6. Train classification models
7. Evaluate model performance
8. Compare the results

## Conclusion

The Iris Flower Classification project successfully classified Iris flowers using Machine Learning.

Both Logistic Regression and K-Nearest Neighbours performed well on the dataset. KNN achieved an accuracy of 100% on the test set, while Logistic Regression achieved 96.67%.

This project demonstrates the basic workflow of a Machine Learning classification problem.
